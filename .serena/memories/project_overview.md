# Network Fault Simulator - プロジェクト概要

## プロジェクトの目的
ネットワークの通信障害をシミュレーションし、視覚的に理解できるWebアプリケーション。
教育目的で作られており、ネットワーク構成の可視化、ping疎通確認、故障診断機能を提供する。

## 主な機能
1. **ネットワーク構成図の表示**: ルータ、スイッチ、PC、サーバを含む企業ネットワークの視覚化
2. **ping疎通確認**: デバイス間の接続テストをシミュレーション
3. **故障シミュレーション**: 任意のデバイスを故障状態に設定
4. **故障診断**: 疎通失敗の原因分析と推奨アクション提示

## テクノロジースタック
- **フロントエンド**: Streamlit (Python Webアプリフレームワーク)
- **データ可視化**: Plotly (インタラクティブグラフ)
- **ネットワーク解析**: NetworkX (グラフ理論ライブラリ)
- **データ処理**: Pandas, NumPy
- **開発環境**: Python 3.11, Dev Container

## アーキテクチャ
- 単一ファイル構成 (`app.py`)
- オブジェクト指向設計（クラスベース）
- Streamlitのセッション状態管理を使用
- リアルタイムなUIアップデート
