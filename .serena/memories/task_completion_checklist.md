# タスク完了時のチェックリスト

## コード品質チェック
1. **構文エラーチェック**
   ```bash
   python -m py_compile app.py
   ```

2. **型チェック**
   - VS Code内でPylanceによる自動チェック
   - 赤い波線や警告がないことを確認

3. **インポート整理**
   - 未使用インポートの削除
   - インポート順序の確認（標準→サードパーティ→ローカル）

## 機能テスト
1. **アプリケーション起動確認**
   ```bash
   streamlit run app.py
   ```

2. **手動機能テスト**
   - ネットワーク構成図の表示
   - ping疎通確認の動作
   - 故障シミュレーションの動作
   - 故障診断の実行

3. **ブラウザ表示確認**
   - レイアウトの崩れがないか
   - エラーメッセージが表示されていないか

## ファイル整理
1. **不要ファイルの削除**
   - `__pycache__`フォルダ（自動生成）
   - テンポラリファイル

2. **依存関係の更新**
   - 新しいライブラリを追加した場合は`requirements.txt`を更新

## 注意事項
- このプロジェクトにはユニットテストが含まれていない
- 手動テストが主要な品質保証手段
- Streamlitアプリのため、ブラウザでの動作確認が必須
